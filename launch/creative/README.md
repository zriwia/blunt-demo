## Source Files

- `ad-boards.html`

The HTML board is the source for the static image ads.  
Each creative can be opened with a `variant` query param:

- `ad-boards.html?variant=square-01`
- `ad-boards.html?variant=square-02`
- `ad-boards.html?variant=portrait-01`

## Intended Use

- `blunt_manifesto_15s.mp4`: primary paid video creative
- `blunt_manifesto_40s.mp4`: longer optional video / landing support
- `blunt_ad_square_01.png`: first image ad, thesis-led
- `blunt_ad_square_02.png`: second image ad, trust-gap framing
- `blunt_ad_portrait_01.png`: portrait backup creative for placements that prefer taller layouts

## Notes

- The static creatives are deliberately bold and text-forward so the product wedge is obvious on first glance.
- The video asset is already lightweight enough to upload quickly.
- If a platform prefers portrait later, use the `portrait-01` artboard as the next render source.
